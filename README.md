## Описание проекта
Учебный веб-проект для освоения базовых команд Git:
создание репозитория, коммиты, ветки, публикация на GitHub.

## Структура
- `index.html` — главная страница проекта
- `style.css` — стили
- `screenshots` - папка со скриншотами
- `script.js` — скрипты
- `README.md` — описание проекта
- `REPORT.md` — отчёт по лабораторной работе
- `.gitignore` — исключённые файлы (node_modules, логи, файлы IDE)

## Как открыть
Открыть `index.html` в браузере
(или запустить `npx live-server`, если установлен Node.js).

## Использованные команды Git
`git init`, `git add`, `git commit`, `git branch`, `git merge`,
`git remote add`, `git push`, `git pull`
